# Portfolio NIHASY

Page unique, sans dépendance : ouvrir `index.html` dans un navigateur.

Tous les textes, chiffres, projets et témoignages sont **factices** : à remplacer par les vrais.
À personnaliser en priorité :

- `[Prénom Nom]`, e-mail, téléphone, liens Instagram / LinkedIn (section Contact) ;
- numéro WhatsApp : variable `WA` dans le script (format `261340000000`, sans le +) ;
- contenu des trois offres (aucun prix affiché : devis sur demande) ;
- le visuel « Votre portrait ici » (canvas `#heroCanvas`) peut être remplacé par une photo.

Déploiement : glisser le dossier `portfolio/` sur Vercel ou Netlify (site statique).

Animations : chargement avec compteur, titres lettre par lettre, curseur personnalisé et boutons magnétiques (ordinateur),
bandeaux qui suivent le défilement, carrousel 3D, faisceau lumineux, texte chrome brillant. Toutes se coupent si
l'appareil demande moins d'animations.
