# Portfolio NIHASY

Page unique, sans dépendance : ouvrir `index.html` dans un navigateur, ou glisser le dossier `portfolio/`
sur Vercel ou Netlify (site statique).

Tous les textes, chiffres, projets et témoignages sont **factices**. À personnaliser en priorité :

- `[Prénom Nom]`, e-mail, téléphone, liens Instagram / LinkedIn (section Contact) ;
- numéro WhatsApp : variable `WA` dans le script (format `261340000000`, sans le +) ;
- contenu des trois offres (aucun prix affiché : devis sur demande) ;
- le visuel « Fig. 01 · Votre portrait ici » (canvas `#heroCanvas`) peut être remplacé par une photo.

## Partis pris

- Grille de 12 colonnes (8 sur tablette, 4 sur téléphone). Touche **G** pour l'afficher.
- Filets fins plutôt que des cartes ; listes indexées (offres, parcours, projets, questions).
- Deux voix typographiques : Archivo noire très large, et Archivo fine italique très condensée.
- Détails du lieu : heure d'Antananarivo en direct, coordonnées, « Manao ahoana » à l'ouverture.
- Typographie française : espaces fines insécables avant « ? : ! », guillemets suspendus.
- Alignement optique : chaque ligne de grand titre est décalée du blanc de sa première lettre ;
  le nom en pied de page est calé au pixel sur la largeur de la grille.

## Contrôles effectués

8 tailles d'écran (320 → 1920 px, tactile et souris) : aucun débordement, aucun texte coupé,
zones tactiles ≥ 44 px, aucune erreur JavaScript. 27 tests de fonctionnement (menu, carrousel au doigt
et à la souris, offres, formulaire WhatsApp, copier, témoignages, FAQ, clavier, mode « animations réduites »).
